# FlappyBird in the Console
This Projects includes the well-known Game "FlappyBird" in the Console written in C#
I updated the Project to .NET 8

# Run
You can run the Project by simply clone the repo and then type this in your console:
```
cd src
dotnet run
```

It should build in your newest version
